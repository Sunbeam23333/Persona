# 首次接入接线

本轮只改 `:feature:settings`。`PairingScreen` 包含欢迎、配对和准备清单，完成或跳过清单才调用 `onReady`。分段进度沿用 `:core:designsystem` 的 `StepProgress`，没有增加 HTTP 调用。

App 已在 Root 保留配对流程直到 onReady，再进入主界面；SettingsServices 已提供诊断及锁屏测试，配对页由可滚动容器承载。targetSdk 已升到 37，本地网络权限门禁和设置返回恢复均已接，真实 Android 17 行为仍待验收。

通知、电池、自启动、系统设置等项目的跳过、手动确认及完成状态存入原有 `settings-readiness` 偏好，每条选择带时间戳，不保存配对凭据。设置返回时重新读取系统状态；用户确认不能代替系统可查询的结果。系统状态返回时重查；兼容手工记录已在退出和重配前清除，不跨配对继承。

凭据保存后若机器刷新失败，本页只重试刷新，避免再次兑换一次性配对码。旧 hub 的兑换回退沿用既有 PairingService，未改网络层。
