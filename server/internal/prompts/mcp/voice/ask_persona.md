把一件事交给 Persona 主对话去做：它是能用用户全部数据和工具的完整助手（日程、邮件、飞书、文档、各台电脑、定时任务、写东西……），比你能做的多得多，但要几十秒到几分钟。你自己的工具答不了、或者用户要办一件需要动手的事时用它。它不会马上返回：调用时告诉用户一声已经交给主对话了，然后照常聊；主对话这一轮做完，这次调用的结果就是它的回答（可能要几分钟），那时再告诉用户。task 要写清楚、自成一体，第一句就是要做的事（主对话看不到这次语音的上下文）。

```json
{
  "type": "object",
  "required": ["task"],
  "properties": {
    "task": {"type": "string", "description": "要主对话做的事，完整的一句或几句话"}
  }
}
```
