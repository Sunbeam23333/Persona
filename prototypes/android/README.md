## 范围

- 只画 Android：这一轮 iOS 只读不改。风格是原生的 Material You，但没有用系统动态取色，而是一套固定的中性色调，方便截图对比。
- 状态色（需要你 / 工作中 / 完成未看 / 已看）和 iOS 同一张表（`ios/Shared/StatusPalette.swift`），其他语义色取自 `ios/Shared/Theme.swift`。
- 页面上的名字、地址、数字全是编的：地址用文档地址段（`2001:db8::/32`、`192.0.2.0/24`）和 `example.com`，人名用「小王」这类占位。
  TLS 端口 `18662` 也是示例（方案里 TLS 端口可配，还没定默认值）。
- 延迟（`23 ms` 这类）是示例，不是实测；心跳间隔是设计值，要真机测过耗电再定。

## 可体验

- 左侧目录切页面，← → 键顺序翻；右边是这一页要看的点和对应的文档章节。
- 左上切浅色 / 深色、360 / 320 宽。
- 地址参数：`#screen=<页面 id>&theme=light|dark&w=320&only=phone`。`only=phone` 只显示手机，截图用；`audit=1` 在页面末尾列出被裁切、折行或伸出屏幕的按钮（截图检查用）。
- 手机里能点：底部导航、返回、列表行、请求卡、工作行的展开 / 收起、搜索结果、「返回搜索前位置」、状态行、筛选标签、提问选项、分享目标、开关。动作按钮点了弹一条示意的提示（比如「已回传你的选择」）。
- 授权、计划、完整交互页的输入框可以直接打字：写了拒绝原因「允许」变灰，写了意见两个批准变灰，清空就恢复。

## 原型和原生的边界

- 原型说明的是信息、层级和文案，不是像素规格。字号、间距按 Material 3 的常用值估的，落地以 Compose 的 Material 3 组件和 `spec/tokens/` 为准。
- 没有模拟：动态取色、预测性返回、浮层拖动、键盘弹起、读屏、字体放大、减少动态效果。原生实现按 ux.md 第 8、9 节做。
- 字体用的是打开它的电脑上的系统字体（没有 Roboto 就是苹方），观感和手机上会有差别。
- 通知栏、锁屏照 Android 16 / 17 的样子画的示意；各家国产系统的通知样式不一样，以真机为准。MetricStyle 和状态栏胶囊只有新版本有，老版本退回普通常驻通知（android.md 5.10）。
- 请求、通知、状态之间的数字前后对得上（需要你 3、工作中 2、完成未看 1），但只是一个时刻的截面，页面之间没有真的状态流转。

## 验证记录

- 2026-10-30，headless Chrome（macOS）截图：32 个页面 × 浅色 / 深色，另加 32 张 320 宽。浅色、深色逐张看过，320 宽看了绝大部分；
  改了四轮，每轮改完重拍复查。改掉的问题：任务进度页的类名和别的组件撞了、拒绝原因输入框不随内容长高、窄屏上命令被折成两行、对话页副标题没有省略号、
  MCP 完整页的标题在窄屏折成两行、欢迎页和扫码页的断行、首页建议卡片的标题被截断、深色下品牌图标和背景糊在一起、说明文字里的命令被折开。
- `audit=1` 对 32 个页面 × 360 / 320 宽检查按钮、标签：0 个被裁切、0 个折行、0 个伸出屏幕。用三个故意改坏的样式做过反向验证（裁切、折行、伸出各一个），都能查出来。
- 隐私：`scripts/privacy_check.py` 的词表扫过本目录，0 命中。
- 2026-10-31 用户认可这套原型（32 页，含第五轮的修改），作为 Android 原生界面的设计依据；记进 `docs/archive/android/android-p0-status.md` 的 N54。原型不代替运行验收，原生界面以模拟器截图自查和第 4 轮联合验收为准。
- 2026-10-30 第五轮（对照最新的设计文档）：配对步骤改名「换本机凭据」；常驻通知的渠道改叫「实时状态」（android.md 5.8）；准备清单加「锁屏测试」，诊断页加「后台断开」（hub 记录的断开时段，hub-changes.md 3.10）。改完后 32 页 × 360 / 320 宽重跑 `audit=1`，0 问题；改过的 4 页深浅色重拍看过。
